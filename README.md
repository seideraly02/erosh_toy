# Erosh Toy

Static invitation page, ready for deployment on Netlify.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.

## Netlify

1. Push this repository to GitHub.
2. In Netlify, select **Add new site → Import an existing project**.
3. Choose the GitHub repository.
4. Netlify reads `netlify.toml` automatically. No build command is required; the publish directory is the repository root (`.`).

Every push to the selected production branch will trigger a new deployment.
